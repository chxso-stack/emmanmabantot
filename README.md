# Aralynk — Concept Website

A responsive front-end concept for Aralynk, a local job matching system for BASC students and businesses in San Ildefonso, Bulacan.

## Files
- `index.html` — page content
- `style.css` — styling and responsive layout
- `script.js` — job search/filter and demo modal interactions

## Run locally
Open `index.html` in a browser. No build tools are required.

## Deploy on Vercel
1. Extract this ZIP.
2. Create a GitHub repository and upload the three website files (and this README if desired).
3. In Vercel, choose **Add New → Project** and import the repository.
4. Use the default settings for a static site; no build command is needed. Deploy.

## Important
This is a front-end prototype. Job listings are sample data. Login, user accounts, real applications, messaging, and business job posting are not connected to a database or backend yet. The demo form only displays a local confirmation.
